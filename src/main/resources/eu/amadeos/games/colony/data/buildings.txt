# The buildings of Colony. Change a number, start the game again, play.
#
#   tab       the tab of the panel it is built from: basic, food or crafts
#   size      width and height in tiles; the flag stands below the middle of the bottom row
#   cost      the goods the builder needs, as pairs of good and count; a building without a cost is not
#             built, a map places it
#   seconds   how long the builder works on it, with all goods there
#   work      what the worker does: store, make, fell, plant, quarry, fish, farm, graze, settle or watch
#   needs     the goods that go in, one word each; a|b takes a or b, whichever is there
#   makes     the good that comes out (a settler, for settle)
#   takes     how long one piece of work takes, in seconds, for make, graze and settle
#   radius    how far the worker goes from the house, in tiles; the land claimed, for store and watch
#   tool      yes if the worker needs tools before taking the job
#   keep      how many of each good that goes in wait at the door, at most (2 if not given)
#
# The goods: log plank stone grain flour water bread fish wool cloth tools

building storehouse
  tab basic
  size 3 2
  work store
  radius 12
